## 스마트디지털농업연구실 웹페이지

### 🚀실행방법

>bundle exec jekyll serve

메인 페이지에 보이는 최신 5건(수상 · 논문)은 아래 데이터에서 자동으로 뽑히므로 따로 수정할 필요가 없습니다.

### 📰 News 페이지에 Post 추가 방법
1. `_posts` 폴더에 `.md` 파일을 생성합니다.
2. 파일 이름 형식은 `YYYY-MM-DD-title.md`로 설정해야 합니다. (예: `2026-01-01-2026년.md`)
3. post에 사용할 이미지는 `assets/img/news` 폴더에 정리합니다.

> News 페이지의 **수상 목록은 포스트가 아니라 구글 시트에서 관리**합니다. 아래 `🏆 학술발표 · 수상 내역 수정 방법`을 참고하세요.

### 🏆 학술발표 · 수상 내역 수정 방법 (자동)

학술발표와 수상 내역은 **구글 시트에서 관리**하며, 코드를 수정할 필요가 없습니다.

1. [학술발표목록 시트](https://docs.google.com/spreadsheets/d/1ACLVJ368WL_rCHME4QSjUWlzEWsfSFPV0ayyamyYcU8/edit)에 한 줄을 추가합니다.
2. **매일 오전 9시 20분**에 자동으로 사이트에 반영됩니다.
   급한 경우 GitHub 저장소의 `Actions` 탭 → `Sync Google Sheets` → `Run workflow`로 즉시 반영할 수 있습니다.

작성 시 주의사항입니다.
- `비고` 칸에 상 이름을 적은 행만 News 페이지의 수상 목록에 표시됩니다. 비워두면 표시되지 않습니다.
- `주저자`가 비어 있거나 `-`인 행은 수상으로 보지 않습니다.
- `학회`는 약칭으로 적어도 됩니다. 사이트에는 `농공학회` → `한국농공학회`처럼 정식명칭으로 표시됩니다.
- `국문 제목`이 비어 있거나 `-`이면 `영문 제목`이 대신 표시됩니다.
- 언론 보도가 있으면 `뉴스 기사1` / `뉴스 기사2` 칸에 **주소를 그대로** 붙여넣습니다. 셀에 하이퍼링크를 거는 방식은 주소가 전달되지 않으니 사용하지 마세요.
- `연도`는 반드시 네 자리 숫자로 적습니다.

시트에 오류가 있으면 반영이 중단되고 사이트는 직전 상태를 유지합니다. 실패 여부는 `Actions` 탭에서 확인할 수 있습니다.

### 🥇 경진대회 · 개인 수상 추가 방법

학술발표가 아닌 수상(창업 경진대회, 아이디어 대회, 교수 개인 수상 등)은 `_data/awards_manual.yml`에 추가합니다.

```yaml
- year: "2025"
  who: 정재영·석승원·장은수              # 여러 명이면 가운뎃점(·)으로 연결
  title: 저수지 운영 인공지능 모델 개발     # 없으면 생략 가능
  venue: KSAE AX-Water Challenge 2025
  award: 대상(농림축산식품부 장관상)
  detail: /news/ksae-ax-water-2025/      # 상세 페이지가 있으면 (선택)
  links:                                 # 언론 보도가 있으면 (선택)
    - https://example.com/article
```

시트에서 가져온 수상 내역과 자동으로 합쳐져 연도순으로 표시됩니다.

### 📄 논문 추가 방법

논문은 아직 수동으로 관리합니다. `_data/publications.csv`에 한 줄을 추가하면 됩니다.

| 열 | 설명 | 예시 |
|---|---|---|
| `year` | 게재 연도 | `2026` |
| `title` | 논문 제목 | |
| `authors` | 전체 저자. 쉼표로 구분 | `석승원, 박혜성, 김태곤` |
| `journal` | 학술지명 | `생물환경조절학회지` |
| `volume` | 권(호). 없으면 비움 | `35(1)` |
| `pages` | 페이지. 없으면 비움 | `26-39` |
| `lang` | 제목 언어 (`ko` / `en`) | `ko` |

- **연구실 구성원 이름은 자동으로 굵게 표시**됩니다. `_data/sitetext.yml`의 팀 정보(`name` / `kor_name`)와 대조하므로, 팀 목록에 없는 사람은 굵게 표시되지 않습니다.
- 영문 제목 논문은 저자도 영문(`Taegon Kim`)으로, 국문 제목 논문은 한글(`김태곤`)로 적습니다.
- 제목이나 저자에 쉼표가 들어가면 그 값 전체를 큰따옴표로 감쌉니다. (예: `"사회, 경제, 환경 영향 비교"`)
- 첫 줄(열 이름)은 수정하지 마세요.

### 👥 인원 수정 방법
1. `_data/sitetext.yml` 파일에서 인원 정보를 수정합니다.
2. `number_educ` 필드를 통해 다음과 같이 구분합니다.
    - `1`: 교수님
    - `2`: 박사님
    - `4`: 석사 과정
    - `5`: 학부 연구생
    - `6`: 스태프
    - `7`: 졸업생
3. 인원의 이미지는 `assets/img/team` 폴더에 정리합니다.

> 여기에 등록된 이름(`name` / `kor_name`)이 논문 저자의 굵게 표시 기준이 됩니다. 목록에 없는 구성원은 논문에 이름이 있어도 굵게 표시되지 않습니다.

### 🔬 Research 페이지 수정 방법
1. `_data/sitetext.yml` 파일의 `research > fields` 아래에서 연구 분야를 수정합니다.
2. 각 항목은 아래 4개의 필드를 포함해야 합니다.
    - `title`: 분야 제목
    - `desc`: 설명
    - `image`: 대표 이미지 경로
    - `alt`: 대체 텍스트
3. 대표 이미지는 `assets/img/focus` 폴더에 정리합니다.

### 🔗 Links 페이지에 항목 추가 방법
1. `_data/sitetext.yml` 파일에서 `links > items` 아래에 링크 항목을 추가합니다.
2. 각 항목은 아래 4개의 필드를 포함해야 합니다.
    - `title`: 영어 제목
    - `text`: 한글 제목
    - `url`: 프로그램 주소(url)
    - `image`: 대표 이미지 경로
3. 대표 이미지는 `assets/img/links` 폴더에 정리합니다.
